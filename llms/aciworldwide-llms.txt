# ACI Worldwide — Open Payment Platform (PAY.ON / OPPWA)

> ACI Worldwide (NASDAQ: ACIW) is a global real-time payments software company. Its Open Payment Platform exposes a single unified RESTful API (the PAY.ON / OPPWA gateway) for accepting and managing electronic payments worldwide — server-to-server, the hosted COPYandPAY widget, mobile SDKs, and Pay by Link.

## APIs
- [ACI Open Payment Platform (OPPWA) REST API](https://docs.aciworldwide.com): payments, checkouts, tokenization/registrations, back-office capture/refund/reversal, 3-D Secure, risk/fraud, recurring payments, webhooks, reporting. Base URL (live) https://eu-prod.oppwa.com/v1, test https://eu-test.oppwa.com/v1.
